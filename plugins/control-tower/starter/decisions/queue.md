# Decisions queue

Open questions for the founder. The Chief of Staff pulls them into each decision pack. When an item is answered or defaulted, move it to `DECISIONS.md` and delete it here.

Format (every field required):
```
## Q-0001 · <short title>
- From: <role> · Raised: YYYY-MM-DD
- Key: yes|no   (yes = founder-only, never defaulted)
- Question: <one sentence the founder can answer>
- Options: A) ... B) ... C) ...
- Default: <option>   (applies if unanswered by the deadline; "none" for keys)
- Undo: <how to reverse the default>
- Deadline: YYYY-MM-DD HH:MM
- Risk: low|medium|high
```
